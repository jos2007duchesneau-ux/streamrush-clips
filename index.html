StreamRush Clips

StreamRush Clips is a personal publishing tool used by a single creator to post short vertical clips of streamers who run official clipping campaigns (for example Lacy's campaign on Content Rewards) to the creator's own YouTube and TikTok accounts. Every clip is reviewed (rights, subject, audio and video quality) before it is posted.

The tool uses the official TikTok Login Kit and Content Posting API only. It never posts without the creator's authorization and it can be disconnected at any time from TikTok's settings.
